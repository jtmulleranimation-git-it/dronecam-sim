DroneCam Sim

Your DroneCam rig on the iPad: the same flight modes, sticks and tuning as the Unreal plugin, for practice anywhere, offline.

Pair your Xbox controller in iPad Settings › Bluetooth, then press any button on it. Tap ? any time for controls.

Takes

Each take is a dronecam-path file, the same format your Unreal recorder writes. Share / Save sends it with AirDrop or to Files (on PC it downloads). Copy it into Saved/DronePaths in your project to replay it with the Drone Path Player. The car's path is saved in the same file.

PlayStation controller (DualSense)

Same buttons, same places: ✕ = A, ○ = B, □ = X, △ = Y, L1/R1 = LB/RB, L2/R2 = LT/RT, Create = View, Options = Menu. On iPad, Create takes screenshots by default, so reset with the ↺ button at the top right, or turn that off in iPad Settings › General › Game Controller.
